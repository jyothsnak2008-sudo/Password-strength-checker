# Password Strength Checker

## Project Overview

The Password Strength Checker is a Python-based cybersecurity mini project that evaluates the strength of a user's password and provides suggestions to improve password security.

---

## Features

- Checks password length
- Checks uppercase letters
- Checks lowercase letters
- Checks numbers
- Checks special characters
- Displays password strength
- Gives security suggestions

---

## Technologies Used

- Python 3
- VS Code

## Sample Output

### Weak Password

```
Enter Password: hello

Password Strength : Weak

Suggestions:
- Use at least 8 characters.
- Add at least one uppercase letter.
- Add at least one number.
- Add at least one special character.
```

### Medium Password

```
Enter Password: Hello123

Password Strength : Medium

Suggestions:
- Add at least one special character.
```

### Strong Password

```
Enter Password: Hello@123

Password Strength : Strong

Excellent! Your password is secure.
```
